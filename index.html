Privacy

Your usage stays
on your Mac.

  • Credentials in the Keychain

    Session cookies and keys live in a single login-Keychain item, on this device only, never synced.

  • No third-party telemetry

    History is stored locally with SwiftData. Provider responses are never cached to disk.

  • Talks only to your providers

    Network access is limited to the providers you connect, plus GitHub for optional update checks.

  • Read-only local files

    OpenCode's database and Claude Code's session logs are read, never written. The data never leaves the Mac.

Install

Up and running
in a minute.

01

Download the app

Grab the latest .pkg or .zip from GitHub Releases. After each update, macOS asks once to let TokenMon read its Keychain item. Choose Always Allow.

Latest release
02

Or build from source

Requires Xcode 16 or later. Installs a Release build into /Applications.

$ git clone https://github.com/faulknerpearce/token_monitor.git
$ cd token_monitor
$ make install
03

Sign in to your providers

Click the menu bar item, pick a provider, and choose Sign In…. Usage appears after the first refresh. Repeat for every plan you want to track.
